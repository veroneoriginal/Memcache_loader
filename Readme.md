В этом домашнем задании необходимо переделать готовый однопоточный скрипт,
загружающий логи трекера мобильных приложений в кластер memcache'ей.
Исходники находятся в папке homework-126212-2b1c47.

Скрипт нужно сделать конкурентным, воспользовавшись возможностями многопоточной/многопроцессной обработки,
для того чтобы оптимизировать время загрузки данных.


----
Скрипт парсит .tsv.gz файлы с данными трекера установленных приложений и загружает их в memcache в формате protobuf.
Ключ — тип_устройства: идентификатор,
значение — сериализованное сообщение UserApps (список приложений + координаты).

Архитектура

1) multiprocessing.Pool — параллельная обработка нескольких .tsv.gz файлов
2) threading внутри каждого процесса — 4 потока-писателя, по одному на тип устройства (idfa, gaid, adid, dvid),
   каждый пишет в свой инстанс memcache
3) Главный поток процесса читает строки и распределяет их в очереди по типу устройства
4) Потоки-писатели забирают данные из очередей и пишут батчами через set_multi
5) Файлы переименовываются (с точкой-префиксом) в хронологическом порядке после обработки всех

Структура проекта

memcache_loader/
├── source/
│   ├── __init__.py
│   ├── appsinstalled.proto      # protobuf-схема
│   ├── appsinstalled_pb2.py     # сгенерированный protobuf-код
│   ├── config.py                # константы и настройки
│   ├── memc_load.py             # точка входа, CLI, main
│   ├── parser.py                # парсинг строк TSV
│   ├── processor.py             # обработка файла, оркестрация потоков
│   ├── writer.py                # потоки-писатели, батчевая запись
│   └── test.py                  # тесты
├── data/                        # папка для .tsv.gz файлов
├── docker-compose.yml           # memcache-кластер (4 инстанса)
├── Makefile
├── requirements.txt
└── README.md
